# iPhone 快捷指令 · 一键记一根

通过 iOS 快捷指令调用 Worker 的快速记录接口 `GET /api/tap?k=<你的口令>`，
点一下就在服务端打一个时间戳，然后弹通知确认。

## 搭建步骤

1. 打开 **快捷指令** App → 点 `+` 新建 → 命名为「记一根」。
2. 添加操作 **获取 URL 内容**（Get Contents of URL）：
   - URL：`https://your-domain.example.com/api/tap?k=你的口令`
     - 把域名换成你部署 Worker 的地址（或绑定的自定义域名）
     - `k` 换成你在 Worker 环境变量里设置的 `APP_KEY`（没设口令可省略 `?k=`）
   - 方法：`GET`
   - 「头部」留空即可
3. 添加操作 **显示通知**：
   - 文本：`已记一根`
   - 播放声音：开（可选）
4. 点右下角 ▶ 运行一次测试，收到通知、网页端数字 +1 即成功。

## 触发方式（任选）

| 方式 | 设置位置 |
|------|----------|
| 桌面图标 | 快捷指令 → 分享 → 添加到主屏幕 |
| 轻点背面 | 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下/三下 → 选「记一根」 |
| Apple Watch | Apple Watch 的快捷指令 App 中直接运行 |
| Siri | 对 Siri 说「记一根」（快捷指令名即可触发） |
| 锁屏/操作按钮 | 设置 → 操作按钮 / 锁屏自定义，绑定该快捷指令 |

## 安全提示

- `k=` 口令会出现在 URL 里，建议同时把 Worker 部署在自定义域名下，并定期更换口令。
- 如果担心口令泄露，可改用请求头方式：在快捷指令的「头部」里添加
  `x-app-key: 你的口令`，URL 里就不带 `k` 了（服务端两种都支持）。
